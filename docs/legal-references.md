# 法条引用治理规范 — 让"法条"成为有有效期的数据

> 建立原因：2026-09 第三方审计发现本套装 167 处法条引用中 4 处硬伤（《律师法》第38条失效 18 处引用、《合同法》第107条指向已废止法律、欧盟《数字服务法》无标注、刑诉法第46条语义错位），另有 8 处《商标法》引用未锁定版本。根因不是法条功底，而是**引用从未被当作数据资产维护**：写进文档时是对的，过期了没人知道。

## 一、三层分离原则（解耦总纲）

法条相关内容按"离失效的远近"分三层处理，越靠近"写死"越要加约束：

| 层 | 内容 | 处理方式 | 修改频率 |
|---|---|---|---|
| **程序层** | SKILL.md 工作流逻辑（如"核验保密义务边界"） | **只写行为，不写死条号与条文内容**。需要条文时通过元典 MCP（`yuandian_law_vector_search` / `yuandian_rh_ft_detail`）实时检索现行文本 | 几乎不改 |
| **引用层** | 论证、表格中必须出现的"《X法》第Y条" | 引用必须**带版本锁**（《律师法》（2026修正）第41条）+ 来源标签；全部登记进 `registry.yaml` | 法修订时批量迁移 |
| **内容层** | 确需内置的条文全文/要件表（如 `references/` 下的模板） | 同引用层，且**必须**登记并纳入门禁核验；优先只存"条号+要件骨架"，正文运行时检索 | 法修订时逐条更新 |

一句话：**工作流写"做什么"，不写"法条说了什么"；凡写死的，必须有版本锁、来源标签和登记记录。**

## 二、硬性规范

1. **法规名归一**：正文与登记表统一使用元典标准法规名（见 `registry.yaml` 的 `regulations[].name`）。简称（民诉法→民事诉讼法）只允许出现在 `aliases` 里，不允许出现在新写的引用中。
2. **版本锁**：法条引用一律写《法规全名》（版本）第X条，如《商标法》（2019修正）第57条。未锁版本的裸条号引用会被门禁脚本判失败。
3. **条号迁移提示**：当一部法的新修订版已公布未施行，且条号重排时（如《商标法》2026 修订），相关 skill 的资源索引文件必须写明"施行前引用锁定旧版 + 施行后需整体迁移"的警示（参照 `ip-cold-start-interview/references/cn-ip-law-sources.md` 的写法）。
4. **外国法对照标注**：引用域外法（欧盟 DSA、美国法等）必须显式标注"**外国法对照，非中国法依据**"，否则判失败。
5. **来源标签**：继续沿用三级来源标签体系（`[元典检索 YYYY-MM-DD]` / `[国家法律法规数据库]` / `[需核验]`）。已经活库核验的引用，用 `[元典检索 YYYY-MM-DD]` 替换 `[需核验]`/`[模型知识 — 需核验]`——**标签打了就要核，核完就换标签**。

## 三、registry.yaml 登记表

`docs/legal-citations/registry.yaml` 是全库法条引用的唯一台账：

- `regulations`：每部被引用法规的标准名、别名、现行版本、时效状态、最近核验日期。新修订版公布但未施行的，登记 `pending_version` 与 `pending_effective_date`。
- `semantic_notes`：条号迁移、易错点记录（如"律师法保密义务 38→41"）。
- `citations`：关键引用点抽查清单（不必穷举全库，但**修过的每一处必须记录**）。

## 四、verify_citations.py 门禁脚本

位置：`tools/verify_citations.py`（本仓库根的 `tools/` 目录）。

```bash
# 离线审计（CI 默认）：抽取全库引用 → 归一化 → 对照登记表与规则
python3 tools/verify_citations.py

# 生成待核验清单（JSON），供人工/元典 MCP 批量核验
python3 tools/verify_citations.py --json-out citations-todo.json

# 只审计某个 pack
python3 tools/verify_citations.py --pack legal-skillpack-ip-legal
```

判失败（exit 1）的条件：
- 存在未锁版本的裸条号引用（该法规存在已公布未施行的修订版时才判失败；否则仅警告）；
- 存在引用 `pending_effective_date` 未到的新版条号；
- 存在未标注的域外法引用（DSA / U.S.C. / 英美法关键词）；
- 引用的法规不在 `registry.yaml` 登记表（含别名）中。

**发布流程约定**：每次发版前跑一次门禁 + 每季度人工跑一次全量活库核验（元典 MCP `rh_ft_detail` 逐条查 `sxx`）。法条不是"写对过就完"的字符串，是会过期的数据。

## 五、修订操作手册（法修订时的标准动作）

1. 活库确认：新法版本号、施行日、是否条号重排（对照修订版条文）。
2. 更新 `registry.yaml`（新版本、施行日、迁移注记）。
3. 全库替换引用（含中文数字条号），锁定新版本号。
4. 检查资源索引文件，更新"现行版本"表与施行警示。
5. 把 `[需核验]` 类标签换为 `[元典检索 YYYY-MM-DD]`。
6. 跑 `verify_citations.py` 确认清零，登记本次迁移到 `citations`。

历史执行记录：2026-09-09 律师法 38→41（18 处）、合同法 107→民法典 577、刑诉法 46→48、商标法锁 2019 版（20 处）、DSA 补外国法标注。详见各 skill 内核验标签。
