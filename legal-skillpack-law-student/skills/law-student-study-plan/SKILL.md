# /study-plan

1. 加载 `$LEGAL_AGENT_PROFILE_HOME/law-student/profile.md` → 法考目标（客观题/主观题日期）、弱科、每日目标学习时长、培训课程。
2. 如果存在，加载 `$LEGAL_AGENT_PROFILE_HOME/law-student/study-plan.yaml`。
3. 应用下方的框架。
4. 按标志分流：
   - `--build`（默认，如果计划不存在）：走输入闸门（考试、科目、每周小时数、休息日、学习方法）。构建阶段结构 + 前两周的每日排程。写入 `study-plan.yaml`。
   - `--update`（默认，如果计划已存在）：重新读取 `session_history`，调整科目优先级和 `weekly_hours`，填充接下来一段的每日排程。
   - `--status`：今天/本周安排了什么，得分趋势，哪些科目在滑坡，每科下一次排程时间。
   - `--cram`：强制突击模式——80/20 高频考点优先，每日刷题量，考前2-3天减量调整。
5. 写入前：以自然语言总结计划并与学生确认。根据反馈调整。
6. 始终将每周小时数与学生的生活约束做合理性检查。过度激进的计划必然失败。

## 目的

坐下来学习却不知道该学什么——这是时间消失的方式。本技能构建一个计划——距考试多少周、每天几节、每周哪些科目、各种学习类型——然后随着学生实际完成学习进程而自适应。它是一个活的计划，不是一份日历导出。

它也为下游技能（bar-prep-questions、flashcards、drill、irac）提供一个共享的排程以遵循，这样学生每次打开学习进程时不必被问"你今天想学什么"。

## 置信度准则

计划是判断，不是教条。本技能明确标注什么是估计：

- **每专题时间估计**是一般性指导（基于法考培训课程——众合/瑞达/厚大/指南针/华图——的典型时间分配和历年分值分布）。标注为估计——学生实际速度会有差异。
- **科目权重**基于学生自己报告的弱科和学习记录。可信。
- **突击模式中的高频考点优先**基于多年法考出题规律（客观题+主观题各科分值分布）。任何"这个一定会考"的说法标注 `[不确定 —— 历史频率不是预测]`。
- **来源标签：** 所有引用遵循三级标签体系：
  - `[元典 API]` —— 通过元典 MCP 检索并核验
  - `[模型知识 —— 需验证]` —— 来自模型训练数据，建议对照教材或法考辅导资料交叉核对
  - `[用户提供]` —— 学生直接提供的材料或信息

## 工作流

### 步骤1：我们在为什么做计划

> 我们在为什么做备考计划？
>
> 1. **国家统一法律职业资格考试（法考）**（你有一个目标考试日期）
> 2. **特定的法学院期末考试或期末周**
> 3. **常规学期学习节奏**（大纲整理、阅读、各科练习）

对于(1)法考：从业务规范读取考试日期，确认。如果未录入考试日期，询问。
对于(2)法学院考试：询问哪门课、什么日期、什么形式。
对于(3)学期：询问学期结束日期作为锚点。

### 步骤2：输入——一次一个，等待每个回答

**逐个提问，等待回答。** 不要把所有问题堆在一个提示里然后往下走。

- **考试日期：** 已确认？（法考：客观题和主观题分别在什么时候？如果业务规范中只有其中一个日期，请学生补充另一个。）
- **备考状态：** 是第一次备考还是第N次？脱产备考还是在职/在读备考？
- **要覆盖的科目：** 基于司法部发布的国家统一法律职业资格考试大纲。核心科目包括：
  - **卷一（公法卷）：** 中国特色社会主义法治理论、法理学、宪法、中国法律史、国际法、司法制度和法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法
  - **卷二（私法卷）：** 民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法（含仲裁制度）
  
  和学生确认——"有没有我需要增加或去掉的科目？"
- **最强科目：** 最低优先级。仍然复习，不大量训练。
- **最弱科目：** 最高优先级。获得更多学习时段。
- **每周可用小时数：** 现实的，不是理想的。"我能学20个小时"和"我能连续8周每周学20个小时"是两回事。问他们实际能持续维持多少。
- **生活语境合理性检查——强制执行。** 学生给出数字后，问（一次一个问题——不要跳过）：

  > 你说每周 [N] 小时。在我制定计划之前，告诉我你一周里还有什么——工作（每周几小时）、家庭（小孩、照护）、通勤、锻炼、其它考试（考研/考公等）、实习，任何有意义的事情。计划应该适应你的生活，而不是反过来。一个你无法执行的计划比一个更轻但能执行的计划更糟。

  等待回答。然后对照学生报告的生活负荷检验其声称的小时数：

  > 你每周学 [N] 天，大约每天 [X] 小时，在[工作 + 家庭 + 通勤 + 其它]之外。根据我的经验这[现实 / 紧张 / 不可持续]。要在制定前调整每周小时数目标，还是保持并看看第一周情况？

  即使业务规范中的目标小时数在 cold-start 时已经录入过，也不要跳过这一步。业务规范记录的是学生说过的话；生活语境检查记录的是是否可持续。如果检查得出更低的数字，在计划中使用更低的数字，并在 `confidence_flags` 块中注明调整。

  如果学生拒绝分享生活语境（"直接定"），尊重——但添加 `confidence_flags` 条目："生活语境检查被跳过；计划假设每周 [N] 小时是可持续的。如果第二周末执行率低于 [X]%，重新评估。"

- **偏好的学习方法：** 多选。客观题刷题 / 主观题写作 / 背诵记忆 / 整理大纲 / 听课 / 做笔记。将排程权重倾向于学生说他们实际会做的方式。
- **每周休息天数：** 休息日很重要。排程7/7天的计划在第三周就会崩溃。

### 步骤2.5：补充还是替代（培训课程用户）

如果 `$LEGAL_AGENT_PROFILE_HOME/law-student/profile.md` → `培训课程` 是 **众合**、**瑞达**、**厚大**、**指南针**、**华图** 或任何其它结构化培训课程（即不是 `自主` 或 `无`），学生已经有培训课程日历。本技能的计划必须选择两种角色之一——不能在培训课程之外再运行一套完整的平行课表，学生会在中途崩溃。

问，一个问题，等待：

> 你的业务规范说你正在上[众合/瑞达/厚大/指南针/华图]的课。他们发布了每天的学习日历，每个科目和任务都排好了。本计划可以以两种方式运行——选一种：
>
> 1. **补充。** 培训课程是你的主课表。本计划填补空白：弱科多刷题、主观题定向训练、背诵循环查漏补缺。我不会重建培训课程的日历；我在其上叠加。
> 2. **替代。** 你不跟培训课程的日历（可能因为它的节奏不适合你的生活）。我来构建完整计划——科目、小时、阶段、排程——你放弃培训课程日历。
>
> 别选两种都做。同时跑两套完整的课表是学生在第四周崩溃的原因。

等待回答。在 yaml 中记录为 `prep_course_mode: supplement | replace`。

如果**补充**：计划的每日排程更轻——只增加弱科训练和定向练习，不重复培训课程覆盖。在 `confidence_flags` 中标注："补充模式——本计划假设你按[培训课程]的主课表完成主要覆盖。如果你跟不上培训课程的进度，告诉我，我们重新规划。"

如果**替代**：按下方指定构建完整计划。

如果学生的培训课程是 `自主` 或 `无`，跳过此步骤——没有要补充的东西。

### 步骤3：构建排程

从今天开始计算距考试周数。然后：

**常规模式（4周以上距客观题）：**
- 将各周分为阶段：
  - **基础阶段**（前约50%时间）：系统学习所有核心科目，建立知识框架。每科约3-5天，混合听课/精读与少量客观题和背诵。重点：理解体系、搭建知识结构。
  - **强化阶段**（接下来约35%）：加大客观题刷题量，开始主观题（案例分析）训练。所有科目轮流复习。重点：弱科突破、真题训练、高频考点强化。
  - **冲刺阶段**（最后约15%，客观题前）：聚焦 `session_history` 中的最薄弱环节，整套模拟考试，对强科做轻量回顾。重点：模拟考试、查漏补缺、考前状态调整。
  - **主观题特训阶段**（客观题后至主观题前，约3-5周）：完全转向主观题训练——案例分析、论述题、法律文书写作。客观题已考完，不再回头。
- 按弱科加权：弱科获得强科约2倍的时间。
- 逐日排程：哪个科目、哪种方法、多长时间。为学生的实际生活留出余量。

**突击模式（< 4周距客观题）：**
- 标注："你距客观题不到四周了。这是突击模式——计划优先覆盖高频考点而非全面覆盖。你会留下知识空白。在这个时点这是必然的取舍。"
- 80/20优先级：历年分值最高的科目（民法、刑法、民诉、刑诉、行政法、商经法）获得主要时间。分值较低的科目（中国法律史、司法制度与法律职业道德等）获得最小可行覆盖。
- 每日排程：客观题刷题每天进行（此时题量很重要），主观题隔天一次，每周一次整套模拟。
- 考前2-3天保证睡眠和减量。不要在考前前一天排高强度刷题。这是真的——考试前一晚通宵刷题的学生分数更低。

**法考各科历年分值参考（基于多年客观题+主观题统计，`[模型知识 —— 需验证]`）：**

| 科目 | 客观题权重 | 主观题权重 | 说明 |
|------|----------|----------|------|
| 民法 | 高 | 高 | 客观题约20-25分，主观题常考综合案例分析 |
| 刑法 | 高 | 高 | 客观题约20-25分，主观题常考案例分析 |
| 刑事诉讼法 | 高 | 高 | 客观题约15-18分，主观题常考程序分析 |
| 民事诉讼法（含仲裁） | 高 | 高 | 客观题约15-18分，主观题常考 |
| 行政法与行政诉讼法 | 中高 | 中 | 客观题约12-15分，主观题偶尔出现 |
| 商法 | 中 | 中高 | 客观题约10-12分，主观题公司法和破产法较高频 |
| 经济法 | 中 | 低 | 客观题约8-10分，主观题较少单独出现 |
| 宪法 | 中 | 低 | 客观题约8-10分 |
| 法理学 | 中 | 低 | 客观题约8-10分 |
| 中国特色社会主义法治理论 | 中 | 高 | 客观题约8-10分，主观题论述题必考 |
| 国际法（公法/私法/经济法） | 中 | 低 | 客观题约8-10分 |
| 知识产权法 | 中低 | 低 | 客观题约5-8分 |
| 环境资源法 | 低 | 低 | 客观题约4-6分 |
| 劳动与社会保障法 | 低 | 低 | 客观题约4-6分 |
| 中国法律史 | 低 | 无 | 客观题约3-4分，主观题基本不考 |
| 司法制度和法律职业道德 | 低 | 低 | 客观题约4-6分 |

> **注意：** 上表为历年分值分布经验总结 `[模型知识 —— 需验证]`。司法部每年发布的最新考试大纲和分值分布可能有所调整。请以司法部官网 (http://www.moj.gov.cn) 发布的最新大纲为准。各培训机构的精讲讲义也会标注当年各科预计分值。

### 步骤5：与学生确认

**表头——每次在聊天中展示和在任何与 YAML 并列保存的自然语言计划文件上都必须有。** 摘要的第一行（以及任何 `study-plan.md` 配套文件的第一行）必须是插件配置 `## 输出` 中的原文表头：

```
学习笔记 —— 不构成法律意见
```

表头不放在 YAML 本身内部（它是数据文件），但必须放在你展示给学生的自然语言摘要和任何在 YAML 旁边保存的人类可读计划文件上。这不是事后的免责声明——它是这份输出的身份标识。不得省略、改写或移位。

在保存前以自然语言（非原始 YAML）总结计划，表头置顶：

> 学习笔记 —— 不构成法律意见
>
> 这是我制定的计划。距客观题 [X] 周，距主观题 [Y] 周。每周 [Z] 小时，[N] 个学习日。弱科（刑法、刑事诉讼）获得约2倍时间。四个阶段：基础阶段到 [日期]，强化阶段到 [日期]，冲刺阶段到 [客观题日期]，主观题特训到 [主观题日期]。我已经排好前两周的逐日计划。之后按周分配——我会在你完成各阶段学习后逐步填充每日排程，让计划跟随你的实际进度自适应。
>
> 感觉对吗？太激进？太轻？有遗漏的科目？

根据回答调整。然后写入。

## 计划自适应

每次学习完成后（通过 bar-prep-questions、flashcards、drill、irac），对应的技能追加到 `session_history`：

```yaml
session_history:
  - date: 2026-05-17
    subject: 刑法
    type: 客观题
    n_questions: 30
    score: 18
    weak_subtopics: [共同犯罪, 罪数形态]
```

在下次 `/law-student:study-plan --update` 运行时（或任何技能检测到计划过期时）：
- 得分持续偏低的科目在 `priority` 和 `weekly_hours` 中升级。
- 科目内的弱专题被标记，在下次该科目的排程学习中被重点安排。
- 如果学生在落后（排程的学习未出现在记录中），调整：要么压缩覆盖范围，要么标注差距并询问。
- 如果学生超前，腾出时间做更深的弱科训练。

## 模式

`--build`（默认）——全新计划
`--update` ——重新读取 `session_history` 并调整权重，填充后续每日排程
`--status` ——今天/本周有什么安排，得分趋势如何，什么在滑坡
`--cram` ——强制突击模式，即使距考试超过4周（用户覆写）

## 集成

- `/law-student:session <科目> <n>` 将结果写入本计划的 `session_history`。
- `/law-student:bar-prep-questions` 读取计划以知道今天排程的是什么科目。
- `/law-student:flashcards` 可以 `--session <n>`，结果落入该计划。
- `/law-student:socratic-drill` 和 `/law-student:irac-practice` 学习完成也追加。

**连接状态：**
- 如已连接：✓ "元典 MCP 已连接——法条引用可自动核验。"
- 如未连接：✗ "元典 MCP 未连接——引用标记 `[模型知识 —— 需验证]`。"

## 本技能不做什么

- **保证你通过法考。** 计划是脚手架。努力在你自己。
- **预测考试。** 突击模式使用历史各科频率；高频不等于一定考。
- **替代你的培训课程排程。** 如果你在众合/瑞达/厚大/指南针/华图，本计划可以补充——不要同时跑两套完整的课表。用一套做主课表。
- **调度你的生活。** 可用小时数是你告诉我的。如果夸大了，计划会在第二周崩溃。诚实一点。
- **法律意见。** 所有输出标注 `学习笔记 —— 不构成法律意见`。你不是律师（还），我也不是。
