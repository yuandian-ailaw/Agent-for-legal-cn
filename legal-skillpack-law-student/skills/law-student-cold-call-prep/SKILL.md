# /cold-call-prep

1. 加载 `$LEGAL_AGENT_PROFILE_HOME/law-student/profile.md` → 课程列表、教师风格、学习风格。
2. 应用以下工作流。
3. 识别阅读材料（案例名称 + 来源、课程、教学大纲上下文）。
4. 预测6-10个可能的问题，覆盖多个类别（法条理解 / 构成要件 / 司法解释 / 学术争议 / 实务应用），按教师已知倾向加权。
5. 用追问模式进行练习——提问、等待、追问、卡住时缩小范围。不给答案。
6. 练习后总结：掌握扎实 / 把握不稳 / 完全不会；课前需要复查什么。

## 真实事项检查

如果学生问的问题听起来像是关于真实情况——他们的合同纠纷、交通事故、家庭财产问题、朋友的刑事案件、真实的金额、真实的截止日期、真实的当事人姓名——停下来。

> "这听起来像是一个真实情况，而不是假设性问题。我无法给你法律意见，你也不能——你还不是执业律师。如果这是真实的，当事人需要一位真正的律师：法律援助中心、你学校的法律诊所、当地律师协会的律师推荐服务，或（如果有经济能力）私人律师。我很乐意帮你理解其中涉及的一般法律概念，但那是学习，不是法律意见。"

注意识别：真实姓名、真实地址、真实日期、具体金额、"我的老板/房东/父母/朋友"、"我收到了传票/通知书/处罚决定"、以天为单位的截止期限。以上任一即为触发信号。

## 目的

中国法学院的教学以法条讲授为主、案例研讨为辅，但课堂提问（无论是随堂点名还是案例讨论）同样考验学生对材料的准备程度。老师对材料烂熟于心，知道要问什么；学生通常只读了一遍。本技能缩小这个差距——预测该材料可能的问题模式，以追问方式训练学生，并暴露没有真正掌握的地方。

不是替代阅读材料。是检验你是否真的读了。

---

## 教学法适配说明

中国法学院的教学方法与美国的判例教学法（Case Method）存在显著差异：

- **美国法学院**以苏格拉底式教学法为主，课堂围绕判例展开——教授不断追问案例事实（Facts）、判决要旨（Holding）、推理（Reasoning）和政策考量（Policy）。
- **中国法学院**以法条讲授为主，案例研讨为辅。课堂可能围绕法条解读、案例应用、学术争议或实务操作展开。

本技能针对中国法学院的实际教学方式进行适配，问题分类和教师风格分类均基于中国法学教育的实际场景。

## 置信度纪律

- 当学生提供案例文本或教材摘录：基于实际文本预测问题。可信。
- 当学生仅提供案例名称：基于模型对该案例的了解进行预测。对任何依赖不确定案例细节的问题标记 `[不确定]`。强烈建议学生先粘贴案例或教材相关内容。
- 如果对案例不够了解：直说。"我对这个案例没有足够可靠的把握——请粘贴案例文本或教材中的相关内容，我可以据此工作。否则我的问题只是有根据的猜测。"
- 当涉及具体法条时：如果元典检索工具有连接，优先检索法条原文；否则标记 `[模型知识 —— 需验证]`。

## 工作流

### 第一步：识别阅读材料 + 课堂背景

- 案例名称和相关法条
- 课程 / 学科领域
- 教师教学风格（从 `profile.md` 课程信息中获取——不同教师的提问重点和追问风格不同）
- 该材料在教学大纲中的位置（用于上下文——是该专题的第一个案例、限定性案例还是反例？）
- 如果学生未提供教师信息：根据课程类型推断默认风格（见下方教师风格分类）

### 第二步：预测问题

中国法学院课堂提问存在可识别的模式。按以下类别预测问题：

**法条理解（基础热身）：**
- 本案涉及的核心法条是什么？法条原文怎么表述？
- 该法条的立法目的是什么？
- 法条中的关键术语如何定义？（如"重大误解""显失公平""善意第三人"等）
- 该法条的适用范围和适用条件是什么？

**构成要件分析：**
- 本案中的法律行为/法律关系的构成要件是什么？
- 各个构成要件在本案中是否满足？为什么？
- 是否涉及构成要件的解释或扩张？
- 该法条是否存在例外规定？本案是否适用例外？

**司法解释与适用：**
- 是否有相关的司法解释？司法解释对此问题如何规定？
- 司法解释与法条原文的关系是什么——细化还是补充？
- 本案的事实能否涵摄到司法解释的规定之下？
- 如果存在多个相关司法解释，它们之间如何衔接？

**学术争议：**
- 本案涉及的法律问题在学界有无争议？
- 不同学说对本案会得出什么不同结论？
- 主流观点和少数观点分别是什么？
- 你赞同哪种观点？为什么？

**实务应用：**
- 如果你是原告/被告的代理律师，你会如何主张？
- 本案对类似案件的处理有什么参考意义？
- 法官在裁判此类案件时通常考量哪些因素？
- 本案裁判的社会效果如何？是否符合立法目的？

**教师特有风格（从 `profile.md` 中的教师信息加权）：**

| 教师风格类型 | 特征 | 加权方向 |
|---|---|---|
| 判例分析型 | 偏好通过判例讲解法律适用，课堂上大量分析案例 | 加重构成要件分析 + 实务应用 |
| 法条讲解型 | 以法条为中心，逐条讲解，辅以简单示例 | 加重法条理解 + 司法解释 |
| 案例研讨型 | 以真实案例为课堂主线，引导学生讨论 | 加重实务应用 + 构成要件分析 |
| 学术理论型 | 注重理论深度，引入比较法和学说争议 | 加重学术争议 + 法条理解 |

选取6-10个问题，跨类别分布。按被第一个问到的可能性排序（法条理解通常最先，然后是构成要件，再是更难的类别）。

### 第三步：追问练习

使用追问式练习模式：

1. 问第1题。等待回答。
2. 如果答案正确且论证充分：确认，进入第2题。
3. 如果答案正确但论证潦草：不放过去。"你结论是对的，但解释一下——为什么法院的推理支持这个结论？"
4. 如果答案错误：不给答案。问一个缩小范围的问题。"这个法条的构成要件有几个？先列出要件再来判断。"
5. 如果卡住：进一步缩小。"在分析本案之前——该法条的适用前提是什么？"
6. 如果完全迷失：告诉学生回去重新阅读。"这说明你需要重新阅读，不是靠猜能蒙过去的。回去读完再来。"

### 第四步：练习后总结

```markdown
# 课堂准备 —— [案例/材料] —— [日期]

**练习问题数：** [N]
**掌握扎实：** [自信 + 正确的问题]
**把握不稳：** [猜测或犹豫的问题]
**完全不会：** [不知道答案的问题]

## 课前需要复查：
- [具体需要复查的内容——搞错的事实、说不清的规则]
- [如果学术争议把握不稳："重读相关论文或教材中的学术观点部分——课堂讨论通常来自这些"]
- [如果法条理解有误："对照法条原文再读一遍——注意关键术语的定义"]

## 课堂上很可能被问到的问题：
- [6-10个问题中前3个——老师最可能开场就问的]
```

## 本技能不能做什么

- **成为老师本人。** 真实课堂提问可能走向任何方向。本技能预测模式；老师会有惊喜。
- **替代阅读材料。** 如果你没有读，本技能无法帮助你——提问依赖你已经消化的内容。
- **不先问你就给你案例的裁判要旨。** 练习模式的规则：我问，你答。
- **预测老师特有的偏门问题。** 如果老师有已知的特殊偏好或研究领域，请在 `profile.md` 课程备注中记录，本技能可以据此加权；否则按一般模式工作。
