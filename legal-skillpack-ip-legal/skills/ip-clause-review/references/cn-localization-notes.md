# ip-clause-review — 中国法适配说明与变更记录

> 上游：anthropics/claude-for-legal 原英文版 clause review 工作流
> 本地化：元力工场团队（中国法适配）；本文最后核验：2026-09-09

## 与英文原版的行为差异

| 维度 | 英文原版 | 中国法适配版 |
|---|---|---|
| 合同效力判断基准 | UCC / common law（外国法对照，非中国法依据） | 《民法典》总则编与合同编（第143-157条、第502条等） |
| 违约责任框架 | repudiation / expectation damages | 《民法典》第577-594条（继续履行/补救/赔偿；减损义务第591条） |
| 条款编号引用 | 条款段落（§） | 合同条款 + 法条双轨引用；法条必须锁版本 |
| 保密条款审查 | 以 NDA 普通法惯例为准 | 结合《反不正当竞争法》（2025修订）第10条商业秘密构成要件审查 |
| 争议解决条款 | 诉讼/仲裁通用 | 仲裁条款有效性四要件（《仲裁法》第16-18条），或法院管辖约定（《民事诉讼法》第35条） |
| 消费者格式条款 | UCC unconscionability | 《民法典》第496-498条格式条款规则 + 《消费者权益保护法》 |

## 使用约束

- 本文件是"改动范围"的地图，不是法律依据本身；审查时法律依据以 cn-ip-law-sources.md 登记的现行版本条文为准。
- 引用条文前须确认时效性（元典检索），不得把本文件中的条号当作已核验结论。
